Cargar Sistema Completo desde 3 Archivos CSV

📋 Sistema de 3 Archivos CSV

Este sistema permite cargar la prueba completa usando 3 archivos CSV separados:

Archivo 1: Preguntas (preguntas.csv)

  • Formato: numero;texto_pregunta;opcion_a;opcion_b;opcion_c;opcion_d
  • Ejemplo: 1;¿Qué es el activo?;Recursos;Deudas;Capital;Ingresos
  • Separador: Punto y coma (;)

Archivo 2: Respuestas Correctas (respuestas.csv)

  • Formato: numero_pregunta;respuesta_correcta
  • Ejemplo: 1;A
  • Respuestas válidas: A, B, C, D, E, F, G, H

Archivo 3: Calificación/Ranking (calificacion.csv)

  • Formato: rango_min;rango_max;calificacion;descripcion
  • Ejemplo: 0;40;Deficiente;Necesita mejorar
  • Uso: Define rangos de calificación según porcentaje

Ejemplo Archivo 1 - preguntas.csv:

numero;texto_pregunta;opcion_a;opcion_b;opcion_c;opcion_d
1;¿Qué es el activo?;Recursos de la empresa;Deudas;Capital;Ingresos
2;¿Ecuación contable?;Ingresos-Gastos;Activo=Pasivo+Patrimonio;Debe=Haber;Ventas-Costos

Ejemplo Archivo 2 - respuestas.csv:

numero_pregunta;respuesta_correcta
1;A
2;B

Ejemplo Archivo 3 - calificacion.csv:

rango_min;rango_max;calificacion;descripcion
0;40;Deficiente;Necesita mejorar significativamente
40;60;Insuficiente;Requiere más estudio
60;70;Aceptable;Aprobado con nivel básico
70;85;Bueno;Buen dominio del tema
85;100;Excelente;Dominio sobresaliente
